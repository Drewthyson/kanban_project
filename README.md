# Kanban-Project
Projeto similar ao TRELLO, com funcionalidade de anexar arquivos em cards.

## Requisitos do Cliente

![Caso de uso](./kanban-project.png)

## Serviços Externos

- Amazon S3 - Bucket p/ armazenamento dos arquivos
- Amazon RDS - Serviço de banco de dados SQL
- Vercel - Deploy da aplicação Frontend - Backend a definir onde será o deploy, talvez no mesmo fluxo do front (se possível)
